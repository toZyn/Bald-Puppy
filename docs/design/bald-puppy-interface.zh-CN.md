# Bald Puppy 终端界面

[English](bald-puppy-interface.md) | [简体中文](bald-puppy-interface.zh-CN.md)

## 目标与范围

保留 Qwen Code 0.27.3（基础版本 038b60e3099a174395f26ed0d1b501eb04d2302d）作为代理引擎，复现 toZyn/Zyn-Old 的终端布局。保留上游许可、供应商、工具、权限选项、会话及键盘命令。参考范围是 `src/tui/app.mjs` 的交互界面，包括对话、输入、事件、选择列表及状态栏。

## 展示决策

- 单边框紧凑横幅最多 72 列，显示品牌、账户/模型和 `cwd:`。继续支持明确配置的字符画、标题及副标题。只有明确启用时才显示启动提示。
- 用户消息采用独立的 `> You` 标题，助手消息采用 `◉ Bald Puppy`。主对话标题位于第 3 列，正文位于第 5 列。续接内容保留正文缩进，不重复标题。
- 保留 Markdown、图片及源内容复制索引。流式回复为标题及光标预留行数：零行不显示，一行仅正文，两行显示标题与正文，三行以上可显示流式光标。
- 主输入采用无框 `❯`，两侧各留三列。其他共享编辑器保留原有边框模式。缓冲区宽度、建议宽度及物理输入法光标位置按实际模式计算；粘贴、编辑、历史及提交/取消行为保持一致。
- 页脚在输入之后显示有限宽度的细分隔线，以及模型、轮数、已用/可用上下文及 `/help`。保留明确配置的状态脚本和权限、Shell、初始化、队列等临时指示。页脚不宣传 Qwen 未实现的退出快捷键。
- 工具/状态事件使用紧凑语义符号。选中项使用琥珀色 `▸`，保留编号、分类及鼠标操作。加载标签左侧缩进五列，固定旋转符和取消区，标签区域可收缩，并约束实际终端宽度。
- 默认深色层级采用白色正文、#cccccc 标签、#999999 弱文本、#888888 次级文本、#d4a054 强调色、#383838 边框及 #aa88cc 工具事件。其他主题使用各自的语义颜色。

## 重绘缺陷与修正

此前只检查组件最后一帧，没有覆盖完整终端输出链路。完整 Ink → PTY → xterm 测试证明：在显示内置长加载短语时，将终端从 100×30 调整为 40×12，再调整为 40×30，会在一个标题上方残留五条横幅顶边。

视口模式此前只在宽度缩小时判定擦除坐标失效。现在任一维度改变后，在布局稳定窗口内清理视口；重放旧帧也要求宽度和高度都一致。一次性 Static 内容立即重新挂载，并在清理窗口结束后再挂载一次，保证代理页签历史在键盘高度改变后仍然可见，同时普通模式不清除原生滚动历史。加载行另外约束自身宽度，防止长标签产生意外的物理换行。

## Markdown 流式展示及工具密度

按截图复现的内容在 40/80 列保持顺序，但显示出横线直接绘制为 Markdown 标记、加粗内部代码标记泄露以及完成文件差异过于冗长。横线改为受宽度约束的分隔线，无序列表统一为圆点，标题使用强调色。加粗和斜体内部内容递归解析，最大深度为 16，保留转义及现有链接校验。无语言输出块默认不显示源码行号，显式用户配置仍优先。

成功完成的内部写入或编辑显示新增/删除行数及已有 Ctrl+O 展开操作。错误、确认、显式完整详情、屏幕阅读器及保存会话截断提示仍保留完整展示。持久化差异和实际操作不变。

虚拟历史显示滚动条时少预算一列，已完成和实时内容都使用实际宽度，防止原本看似能放下的横线或代码换到额外一行。维护中的完整 CLI 本地模拟测试暂停仍有未闭合代码围栏的回答，要求在 40/80 列完成前即可看到格式化标题、嵌套行内代码、圆点和横线，拒绝单字符横线残片，并在释放后验证结尾完整。

## 验证

运行修改组件及下游对话/菜单消费者的定向测试，并运行维护中的 `integration-tests/interactive/tui-header-repaint.test.ts`。该完整 CLI 验收测试采用确定性的本地模型，验证 Unicode 粘贴和编辑后的实际请求、两轮响应、斜杠补全、模型对话框、流式输出、连续宽高调整及一次性 Static 测试场景。

测试通过 `QWEN_HOME` 隔离配置、禁用使用统计/运营遥测，并在 CLI 启动前阻止所有非回环网络。防护验证会拒绝外部 HTTP、HTTPS、TLS、DNS、socket 及 fetch。仅使用模拟凭证和临时运行/证据目录。保存解析后的终端帧及原始 ANSI；终端预览必须来自真实捕获帧。

验收要求构建、类型、静态检查、相关回归和完整 CLI 终端检查成功，且没有重复横幅顶边或丢失输入/页脚。检查普通及窄终端（20、40、80、120 列）、长 Unicode 标签、标题/正文对齐，以及极低高度时的降级。

## 限制

此环境无法测试原生 Android 硬件及真实模型账户。需要 Node 22+，可选原生依赖仍受平台限制。模型选择器在 40×10 终端使用紧凑高度预算，保持选中项和导航可见，放大后恢复完整元数据。保真决策及原实现缺陷详见[固定版本参考审计](zyn-tui-reference-audit.zh-CN.md)。不宣称完全不存在任何缺陷。
