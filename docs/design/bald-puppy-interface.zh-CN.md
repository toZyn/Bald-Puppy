# Bald Puppy 终端界面

[English](bald-puppy-interface.md) | [简体中文](bald-puppy-interface.zh-CN.md)

## 问题与范围

将旧 Codex 源码替换为 Qwen Code 0.27.3，固定版本为 038b60e3099a174395f26ed0d1b501eb04d2302d。保留 Git 历史和上游许可声明。采用 Zyn-Old 的紧凑终端风格，不复用其输入循环。

## 决策

保留 Qwen 的引擎、会话文件、权限、命令名称和主题配置键。增加 bald-puppy 可执行别名。默认深色主题使用绿黑色 #212823、琥珀色 #d4a054 和柔和的元数据颜色。Ink 和 OpenTUI 均采用最大 72 列的紧凑面板，默认不显示标志或空行。继续支持用户明确配置的字符画。终端不足 40 列时取消外边距。截断过长标签，保留自定义主题及无障碍模式。

## 风险与验证

依赖要求 Node 22+。不保证原生 Android 支持。编译并检查 CLI 类型，运行标题、主题、输入、页脚和自定义横幅回归测试。检查 20、40、80、120 列、Unicode 路径、长模型名称、窗口调整、自定义字符画、NO_COLOR 及屏幕阅读器隐藏行为。验收要求可运行的打包产物和相关测试通过；不宣称不存在任何错误。
