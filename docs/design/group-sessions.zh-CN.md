# 群组会话

[English](group-sessions.md)

复用现有 Agent Team 运行时和 Agent View 会话。主代理通过现有工具创建、命名和分配
队友；保留权限检查及工作树隔离。显式模型选择必须传递给 TeamManager；模型必须属于当前配置的服务端点。

主输入框下显示数量受限的圆角卡片，包括名字、模型、状态和任务标题。通过现有键盘
标签或备用屏幕鼠标选择打开完整会话与审批。避免把每个工具事件重复写入主会话。
小屏幕采用紧凑布局，并显示隐藏数量。成员变化时重新测量底部区域。

使用模拟运行时验证命令解析、功能开关、模型传递、小屏幕布局、任务事件和选择行为。
多人协作可能增加令牌消耗。
