## 参考版本

审计版本为 `toZyn/Zyn-Old` 的 `bc8bd1eb2f7f96d3dfbbe601834afc3283e4230c`，主要文件是 [src/tui/app.mjs](https://github.com/toZyn/Zyn-Old/blob/bc8bd1eb2f7f96d3dfbbe601834afc3283e4230c/src/tui/app.mjs)。本文补充[界面设计](bald-puppy-interface.zh-CN.md)。参考实现使用 React 19 和 Ink 7；虽然调色板声明了背景色，终端实际背景仍继承终端设置。

## 工作机制

`UIStore` 是 EventEmitter，保存已完成内容、实时思考与回答缓冲区、加载状态、草稿、消息队列及互斥的确认、选择、输入请求。`_emit` 通过 `setImmediate` 合并更新；流式思考和回答最多每 200 毫秒请求一次刷新。`useStore` 订阅并清理监听器；`useDimensions` 监听终端尺寸并在卸载时清理。

`App` 把已完成内容及动态区域放进可滚动列，状态栏在列外。确认框、选择器或辅助输入框独占输入，否则 `InputBar` 处理文字与斜杠补全。历史项有稳定 ID。完成后的 Markdown 解析为段落、代码、列表、引用及表格；实时回答显示普通文字和末尾光标。

`InputBar` 保存文字、光标、历史和选中建议，通过 ref 防止输入回调使用旧状态。它显示八条斜杠建议，支持 Tab、方向键和 readline 快捷键。原实现忙碌时把普通 Enter 提交加入队列。`App` 单独处理 Escape：500 毫秒内按两次中断或退出。确认默认选中 No，必须明确选择同意。动作语义属于引擎，不属于视觉皮肤。

## 为什么不能直接复制

离线重新计算原始纯函数得到 `wrapText('漢'.repeat(8), 8) = ['漢漢漢漢漢漢漢漢']`，八列预算实际占十六列。退格按 UTF-16 代码单元切片，从 `😀` 删除一次会留下无效单独代理项 `\ud83d`。72 列横幅连同左边距的顶边占 74 列，标题行却占 76 列。选择器只根据宽度决定条目数：40 列时请求八项，即使终端仅十行。这些是源码级反例，不代表所有终端都会出现每一种伪影。

保留 Qwen 的显示列测量、Unicode 编辑器、Markdown、粘贴封装、历史、权限及取消逻辑。不要导入 Zyn 的代理、插件加载器、会话全局变量、console 拦截或信号处理。用 React/Ink 绘制边框。保留长历史下可访问的输入区，不把它移入参考实现的可滚动动态区。保留现有主题及显式用户自定义设置。

## 完成适配

队列预览增加参考邮件图标、弱化斜体和边距，不改变队列内容及执行顺序。模型选择器增加参考标题标记。可用高度少于 18 行时隐藏可选说明及详情，按显示宽度截断标题，使用简短且可访问的导航提示。少于七行时取消装饰边框和垂直空白，使标题、选项及导航仍能显示。选项中的显式换行被限制在单行视口内。错误继续显示，放大后恢复完整详情。有效内部预算至少需要三行（显示错误时为四行）；更小的视口不能同时展示标题、选项和提示。供应商选择、密钥、持久化和权限逻辑不变。

## 验证及限制

为紧凑说明、队列图标及短模型布局提供先红后绿的回归测试。真实 CLI 验收必须在 40×10 显示选中行和 `↑↓`、`Enter`、`Esc`，随后导航、调整尺寸并关闭，不连接实际模型供应商。使用启动前仅允许本地模拟端口的网络防护，重新运行已有两轮 Unicode、粘贴和缩放流程。运行相关组件测试、lint、构建及类型检查。截图来自真实终端单元格，不能用示意图替代。[40×10 模型捕获](../images/bald-puppy-model-40x10.txt)来自仅连接本地模拟服务的成功 PTY 运行，已经导航到第二个模型。

此处无法验证原生 Android/Termux 渲染和真实供应商账户。这是在 Qwen 上适配 Zyn 的视觉与交互层次，不替换 Qwen 引擎，也不保证所有原始快捷键完全一致。
